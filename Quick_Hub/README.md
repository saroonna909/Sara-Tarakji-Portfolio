📱 Quick Hub - Smart Attendance Management System
Quick Hub is a comprehensive web-based platform designed to streamline classroom management and student attendance tracking. It simplifies the process for instructors by using dynamic QR codes and real-time data filtering.

✨ Key Features
Instructor Dashboard: A centralized interface to manage active lectures, materials, and student logs.

Dynamic QR Attendance: Generates real-time, time-sensitive QR codes for secure student check-ins.

Smart Search & Filtering: Advanced search functionality to filter attendance records by student name or ID instantly.

PDF Report Generation: One-click export of attendance logs into professional PDF reports.

Course Materials Viewer: Integrated document viewer for PDF resources within the platform.

🛠️ Tech Stack
Backend: Python & Django

Frontend: HTML5, CSS3 (Bootstrap), and JavaScript

Database: SQLite

Deployment Tools: Ngrok (Secure Tunneling)
